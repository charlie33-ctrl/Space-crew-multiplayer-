SPACE CREW MULTIPLAYER — FULL UPGRADE

Deploy: upload every file in this folder to the ROOT of your GitHub repo and commit. Railway will redeploy the existing service automatically; keep the same public domain.

Persistent accounts/progress (recommended):
1. In the same Railway project click + New -> Database -> PostgreSQL.
2. Railway normally exposes DATABASE_URL to linked services. If it does not, open the web service -> Variables and add DATABASE_URL using the Postgres connection variable/reference.
3. Redeploy the web service once.
4. On the title screen create an account. The status line says whether persistence is connected.

If no DATABASE_URL is present, accounts still work for testing but are memory-only and reset when the server restarts.
